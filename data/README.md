# Local data only

Keep downloaded datasets and uploaded media on your local machine or approved research storage. This repository ignores raw and processed data directories and common audio/video formats. Do not commit datasets, user uploads, credentials, or model weights.

Before using or sharing any data, record the dataset source, label definitions, recording/session identifiers, licence or terms, and intended use in `../docs/dataset-audit.md`. Check whether terms permit research, transformation, and demonstration separately.
